# Domain docs

RecipeTap uses a single context: `GLOSSARY.md` at the repo root and
decision records under `docs/adr/`.

Before exploring an area, read the glossary and relevant ADRs if they
exist. Proceed silently when they do not. Domain-modeling creates them
when terms or decisions are actually resolved.

Use glossary terms consistently in issues, code proposals, and tests.
Call out a conflict with an existing ADR instead of silently overriding it.
