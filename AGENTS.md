## Agent skills

### Issue tracker

Use GitHub Issues in `neusse/RecipeTap`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context glossary and ADR layout. See `docs/agents/domain.md`.

### ChefTap data migration

For requests to recover ChefTap data, merge it into RecipeTap, build, or install
on Android, follow `docs/agents/cheftap-migration.md`. Use real owner-provided
exports and phone data; never substitute sample data or commit personal data.
